# Calendar Application API Documentation


## Overview
This Calendar application is a RESTful service that allows clients to manage events and event categories in a calendar. It supports standard CRUD operations (Create, Read, Update, Delete) using JSON payloads.

**Base URL:** `http://localhost:8080`

---

## **Events**
Represents calendar entries including time, location, and type.

#### **The Event Object**
| Attribute | Type | Description |
| :--- | :--- | :--- |
| `id` | string | Unique identifier for the event (assigned by server). |
| `title` | string | The name of the event. |
| `description` | string | Additional details about the event. |
| `location` | string | Where the event takes place. |
| `eventType` | string | The category name (e.g. "Work", "Lecture"). |
| `startDate` | string | ISO 8601 Date String (e.g. `2026-01-01T09:00`). |
| `endDate` | string | ISO 8601 Date String (e.g. `2026-01-01T10:00`). |

---

## 1. List all events

Returns a list of all event objects.

**Endpoint:**
`GET /events`

**Response:**
Returns a JSON array of event objects.

**Example Response:**

```json
[
  {
    "title": "New Year's Day",
    "description": "Celebration of the New Year",
    "location": "Worldwide",
    "eventType": "Public Holiday",
    "startDate": "2026-01-01T00:00",
    "endDate": "2026-01-01T23:59",
    "id": "1"
  }
] 
```
---

## 2. Search for Events
Search for events using a (partial) match on the title.

**Endpoint:**
`GET /events/:title`

**Path Parameters:**
| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `title` | string | Yes | The title string is used for searching for events (case-insensitive). Also works with partial matches. |

**Response:**
Returns a JSON array of matching event objects.

**Example Response:**
```json
[
  {
    "title": "Team Meeting",
    "description": "Weekly sync",
    "location": "Office 302",
    "eventType": "Work",
    "startDate": "2026-02-10T14:00",
    "endDate": "2026-02-10T15:00",
    "id": "1706198400000"
  }
]
```
---
### 3. Get Event by ID
Retrieves the details of a **single event** using its unique server-generated ID. Includes details of the **related entity** (event type).

**Endpoint:** `GET /events/id/:id`

**Path Parameters:**
| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `id` | string | Yes | The unique ID of the event.|

**Response:**
Returns a single event object. It includes a `relatedType` object containing the details (colour) of the linked event type.

**Example Response:**
```json
{
  "title": "Event to Fetch by ID",
  "description": "This event will be fetched by ID.",
  "eventType": "Work",
  "startDate": "2024-10-12T10:00",
  "id": "1706198400000",
  "relatedType": {
      "name": "Work",
      "colour": "danger"
  }
}
```

**Error Response**
Returns `404 Not Found` if the ID does not exist.

**Example Error Response:**
``` json
{
  "message": "Event not found"
}
```

## 4. Create Events
Creates a new event. The server automatically assigns a unique `id` based on the timestamp.

**Endpoint:**
`POST /events`

**Request Body:**
| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `title` | string | Yes | The name of the event. |
| `description`| string | No | Additional details. |
| `location` | string | No | Event location.
| `eventType` | string | Yes | Must match an existing Category `name`. |
| `startDate` | string | Yes | Start date/time (ISO 8601). |
| `endDate` | string | No | End date/time (ISO 8601). |

**Response:**
Returns the created event object with the `id` generated by the server.

**Example Request:**
```json
{
  "title": "Team Meeting",
  "description": "Weekly sync",
  "location": "Office 302",
  "eventType": "Work",
  "startDate": "2026-02-10T14:00",
  "endDate": "2026-02-10T15:00"
}
```

**Example Response:**
```json
{
  "title": "Team Meeting",
  "description": "Weekly sync",
  "location": "Office 302",
  "eventType": "Work",
  "startDate": "2026-02-10T14:00",
  "endDate": "2026-02-10T15:00",
  "id": "1706198400000"
}
```

## 5. Update Events
Updates an existing event by its ID.

**Endpoint:**
`PUT /events/:id`

**Path Parameters:**
| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `id` | string | Yes | The unique ID of the event to update. |

**Request Body:**
| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `title` | string | Yes | The name of the event. |
| `description`| string | No | Additional details. |
| `location` | string | No | Event location. |
| `eventType` | string | Yes | Must match an existing Category `name`. |
| `startDate` | string | Yes | Start date/time (ISO 8601). |
| `endDate` | string | No | End date/time (ISO 8601). |

**Response:**
Returns the updated event object. Returns `404 Not Found` if the ID does not exist.

**Example Request:**
```json
{
  "title": "Meeting Title",
  "location": "Room 100",
  "startDate": "2026-02-10T12:00",
  "endDate": "2026-02-10T13:00",
  "eventType": "Work",
  "description": "Weekly sync",
  "id": "1706198400000"
}
```

**Example Response:**
```json
{
  "title": "Updated Meeting Title",
  "location": "Room 101",
  "startDate": "2026-02-10T14:00",
  "endDate": "2026-02-10T15:00",
  "eventType": "Work",
  "description": "Weekly sync",
  "id": "1706198400000"
}
```

---

## 6. Delete Events
Removes an event from the calendar.

**Endpoint:**
`DELETE /events/:id`

**Path Parameters:**
| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `id` | string | Yes | The unique ID of the event to delete. |

**Response:**
Returns status `200 OK` on `success` or `404 Not Found` if the ID does not exist.

**Example Response:**
```json
{
  "message": "Event deleted successfully"
}
```

## **Event Types**
Represents the categories an event can belong to (e.g. "Work", "Lecture").

#### **The EventType Object:**
| Attribute | Type | Description |
| :--- | :--- | :--- |
| `name` | string | The unique name of the category. |
| `colour` | string | The Bootstrap colour class (e.g. "primary", "danger"). |

---

## 7. List Event Types
Retrieves all available event categories.

**Endpoint:**
`GET /eventTypes`

**Response:**
Returns a JSON array of EventType objects.

**Example Response:**
```json
[
  {
    "name": "Public Holiday",
    "colour": "success"
  },
  {
    "name": "Lecture",
    "colour": "primary"
  }
]
```

## 8. Create Event Type
Creates a new event category.

**Endpoint:**
`POST /eventTypes`

**Request Body:**
| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `name` | string | Yes | Unique name for the category. Must be unique. |
| `colour` | string | Yes | Bootstrap colour (e.g. "danger", "success"). |

**Response:**
Returns the created object on success (`200 OK`).

**Example Request:**
```json
{
  "name": "Work",
  "colour": "warning"
}
```

**Error Response:**
Returns `400 Bad Request` if the `name` already exists.

**Example Error Response**
``` json
{
  "message": "Event Type already exists"
}
```
